Zo werken de Ravotscore & de Ravotpas 🦊

😄 De Ravotscore — van gezinnen, voor gezinnen

Elke score op Ravot komt van een gezin dat er écht geweest is. Na een bezoek geef je in één tik aan hoe leuk de kinderen het vonden:

😖 🙁 😐 😄 🤩

Het gemiddelde daarvan is de Ravotscore op de fiche (bv. 😄 4.2 (17 gezinnen)). Hoe meer gezinnen scoren, hoe betrouwbaarder — bij heel weinig scores tonen we bewust een voorzichtiger cijfer. Adverteren of betalen verandert nooit iets aan de score zelf: die is en blijft van de community.

Zaken met een ⭐ Partner-badge steunen Ravot financieel. Dat geeft hen zichtbaarheid, maar hun score komt exact zoals bij iedereen van gezinnen zoals het jouwe.

🦊 De Ravotpas — verzamelen met de kinderen

Alles wat jullie op Ravot doen, levert ravotpunten op. Elke actie telt één keer per plek, dus gewoon veel ravotten is de enige weg omhoog:

🐾 Bezoek bevestigen ("wij waren hier!")+{{ pw.geweest }}
😄 Een Ravotscore geven+{{ pw.review }}
🥇 De állereerste score van een plek+{{ pw.eerste_score }} extra
📷 Een foto delen (na goedkeuring)+{{ pw.foto }}
🥇 De állereerste foto van een plek+{{ pw.eerste_foto }} extra
🔎 Een voorziening bevestigen (toilet, verschoontafel …)+{{ pw.veld_stem }}
🧺 Een daguitstap samenstellen+{{ pw.daguitstap }}
🎂 Een feestje organiseren via Ravot+{{ pw.feestje }}
📍 Zelf een nieuwe plek aanbrengen+{{ pw.plek }}

Eerlijk spel: wat kan er per dag?

Ravot beloont echte uitstappen, geen kliksessies. Daarom gelden er dagelijkse grenzen — die halen jullie met normaal gebruik nooit:

  • Maximaal {{ dag_max }} punten per dag per gezin.
  • Maximaal {{ geweest_max }} beloonde bezoeken per dag.
    • {% if veldstem_max %}
  • Maximaal {{ veldstem_max }} beloonde voorziening-bevestigingen per dag.
    • {% endif %}
  • Elke actie telt één keer per plek — dezelfde knop opnieuw indrukken levert niets extra op.

Boven een grens blijven jullie knoppen gewoon werken en komt jullie info netjes binnen; er komen alleen geen punten meer bij die dag.
